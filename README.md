# E-Commerce Sales Analytics

## Project Overview

This project analyzes e-commerce sales data using SQL and Power BI to understand sales performance, profitability, customer trends, product performance, and regional performance.

The project includes SQL data cleaning, KPI analysis, business analysis, advanced SQL analysis, and an interactive Power BI dashboard.

## Tools & Technologies

- MySQL
- SQL
- Power BI
- CSV
